# NomadCourt — Upload and Resubmit Guide

## What GitHub Compare means

A GitHub Compare URL is a GitHub web page that displays the exact differences
between two commits. It is not a source file, contract method, or value entered
in the application.

An immutable comparison uses two complete 40-character commit SHA values:

```text
https://github.com/nikvn89/nomad-court/compare/OLD_COMMIT_SHA...NEW_COMMIT_SHA
```

Because both endpoints are fixed commits, the comparison cannot change later.
Using `main` as one endpoint is convenient but is not immutable because `main`
moves whenever another commit is added.

The NomadCourt steward request asks for the exact dispute-ID decoding fix; it
does not explicitly require a Compare URL. The comparison is optional supporting
evidence here. It is mandatory only when the steward specifically asks for an
"immutable comparison."

## Create the optional immutable comparison

The rejected baseline before the dispute-ID work was:

```text
bda9b855cc89a1496ca596936f7d9ce099a9d318
```

After uploading this final package, open the newest commit on GitHub and copy
its complete 40-character SHA. Substitute it below:

```text
https://github.com/nikvn89/nomad-court/compare/bda9b855cc89a1496ca596936f7d9ce099a9d318...FINAL_COMMIT_SHA
```

Do not submit the placeholder text `FINAL_COMMIT_SHA`. Replace it with the real
SHA generated by GitHub after the upload.
